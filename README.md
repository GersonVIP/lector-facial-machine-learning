# Sistema de Reconocimiento Facial para Asistencia

Proyecto final de la materia Machine Learning.

## Descripción

Sistema de asistencia automatizada mediante reconocimiento facial,
utilizando una Raspberry Pi, cámara y una interfaz de usuario.

## Tecnologías

- Python
- MediaPipe
- OpenCV
- NumPy
- Machine Learning
- Raspberry Pi 3 Model B+
